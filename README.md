# central-hub-app

A web app that will show the Central Hub lab as a map: **areas** (home lab, VPS apps, notebook and library, workshop, Azure parked) and the **rooms** inside them, drawn from catalog files.

**Status: nothing is built yet.** This repository holds only its rules and plans. The first code arrives in a later pull request, after these docs are merged. Run steps and the list of what the app reads and does not do will come with that code.
