# Glossary

- **Area:** a group of rooms shown as one card on the Hub home (for example Home lab).
- **Room:** one part of the lab (for example Keycloak) with status, owner, docs link and exit path.
- **Catalog:** the YAML files in `catalog/` that describe areas and rooms. Describing is all they do.
- **Seam:** a place where a part can be swapped because it sits behind a plain contract.
- **Exit path:** how to remove or replace a part.
- **Parked:** shown on the map but not in use.
